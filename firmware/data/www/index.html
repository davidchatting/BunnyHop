Rabbit

Click an LED to paint it with the selected colour. Drag an ear to move it.

Sketch


        

          How sketches work
          
Write ordinary global-mode p5.js (setup, draw,
          mousePressed…). The rabbit is rabbit
          (see js/rabbit-api.js). Define any of these to react to it:
          onButton(e) (e.clicks), onRfid(e) (e.tag),
          onEars(e) (e.left, e.right), onRecording(e) (e.url).
          Outputs: rabbit.ears(l, r) 0–16, rabbit.leds([5 colours]),
          rabbit.led(i, colour), rabbit.play(url), rabbit.chor(steps).
          Pass {throttle:true} when calling from draw().
