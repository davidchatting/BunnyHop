BunnyHop

Install the BunnyHop firmware and web app on an ESP32 (4 MB flash, e.g. Adafruit Feather ESP32) from this page. The Nabaztag's own firmware is never touched.

Your browser can't flash devices. Use Chrome or Edge on a desktop. Open this page over HTTPS to flash.
  1. Plug the ESP32 in over USB and click Connect.
  2. Pick its serial port (e.g. CP2104) and install.
  3. Leave Erase device unticked to keep an existing rabbit pairing and home Wi-Fi.
  4. When it restarts, join the BunnyHop Wi-Fi network and put the rabbit in setup mode (hold its button while plugging it in, release when all LEDs are blue).

Needs a USB-serial driver for your board (CP210x for the Feather). Source: github.com/davidchatting-bot/BunnyHop
